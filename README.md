# 校园多功能活动与场地协同调度系统 (CampusVenueScheduler)

本项目用于校内活动申报、场地预约及活动物资借用。学生提交申请后，由指导教师初审、场地管理员终审。系统管理员负责账号维护、审计查询和演示数据恢复。

---

## 1. 核心架构与技术栈

- **后端服务**：Python 3.12 + Flask
- **数据存储**：SQLite 3（轻量自包含，开箱即用）
- **前端交互**：Jinja2、原生 CSS 和 JavaScript，无需前端构建
- **鉴权设计**：Flask Session，按学生、指导教师、场地管理员和系统管理员分配权限

## 3. 快速启动

使用 Python 3.12，在项目根目录执行：

```bash
python -m pip install -r requirements.txt
python -m scripts.run_server
```

启动后打开 [系统登录页](http://127.0.0.1:8000/)。首次启动会创建 `var/campus_scheduler.sqlite3`，并写入 5 个账号、12 处场地、8 类物资、18 条预约和 3 条场地锁定记录。后续启动会保留已有数据。示例日期以初始化当天为基准，主要排期在三天后。

执行 `python -m scripts.init_db` 可恢复演示库，系统管理员也可在「数据初始化」页面操作。恢复会清除原有预约、设置和审计记录，并使已有登录失效。

## 5. 基本业务演示

1. 用 `student_01` 登录，在「排期日历」查看综教楼 101 多媒体报告厅，并在空闲时段提交预约，借用 2 支无线麦克风。
2. 退出后用 `advisor_01` 登录，在「待办初审」确认该申请。初审通过的预约会预占场地。
3. 退出后用 `manager_01` 登录，在「场地审批台账」完成终审。批准后可在排期中查看预约，在「物资台账」查看时段余量。
4. 用 `student_02` 申请同场地的重叠时段，系统会显示冲突活动和使用时间。两个时段首尾相接时可正常申请。
5. 用 `student_01` 在活动开始至少 2 小时前取消预约，排期和物资占用随即释放。
