## 部署与用户操作手册

**文档版本**：v1.0.0  
**更新日期**：2026-05-22

### 一、 运行环境与安装配置

#### 1.1 系统与运行依赖要求
- **操作系统**：Windows 10/11，或 Ubuntu 20.04+，macOS 12+
- **Python 运行环境**：Python 3.12+ 官方发行版
- **浏览器**：主流现代桌面浏览器（Microsoft Edge, Google Chrome, Firefox）
- **依赖说明**：所有依赖均为轻量纯 Python 库（仅 `Flask` 与 `Werkzeug`，见 `requirements.txt`），无须安装 Docker 或独立数据库引擎，解压即可运行。

#### 1.2 快速安装与数据初始化（一条命令执行）

打开终端（Windows 推荐 PowerShell），进入工程根目录 `CampusVenueScheduler`：

```powershell
# 1. 安装核心运行依赖
python -m pip install -r requirements.txt

# 2. 一键初始化 SQLite 数据库并灌入演示基准数据
python -m scripts.init_db
```

执行上述脚本后，系统将在 `var/` 目录下生成 `campus_scheduler.sqlite3`，写入场地、物资、账号、示例预约和场地锁定记录。首次启动服务时也会自动创建演示库。对已有库执行初始化脚本会恢复演示数据，清除现有业务记录。

#### 1.3 启动本地 Web 服务

```powershell
# 启动本地服务（默认监听 127.0.0.1:8000）
python -m scripts.run_server
```

启动成功后，控制台将输出服务就绪日志。在浏览器中访问：  
👉 **`http://127.0.0.1:8000`** 即可进入系统登录页面。

### 三、 典型业务操作演练指引

#### 3.1 场景一：社团发起活动与场地预约（学生角色）
1. 使用 `student_01` 登录系统；
2. 点击顶部导航栏 **【场地检索与日历】**：
   - 浏览综教楼、学活中心等可用场地；
   - 点击场地卡片中的 **【查看排期】**，切换至指定日期，查看该场地已被占用的时段；
3. 点击 **【发起活动预约】** 按钮进入填报页：
   - 输入活动名称（如“2026开源技术沙龙”）；
   - 选择活动类型为“学术讲座”，填写预期参与人数（如 80 人）；
   - 选择预约场地（如“综教楼 101 多媒体报告厅”，核定容量 150 人）；
   - 在日历中选定一个空闲时段。预置示例主要安排在初始化日期的三天后；
   - 勾选附带借用物资：无线麦克风 2 支；
4. 点击 **【提交审批】**。系统进行前置冲突校验与容量检查，通过后流转至待初审状态，提示提交成功。

#### 3.2 场景二：两级流转审批与冲突锁定（教师与管理员）
1. 安全退出，切换使用 `advisor_01` 登录；
2. 首页自动展示 **【我的待办事项】**，点击李晓峰提交的沙龙活动进入审核：
   - 查看方案完整性，点击 **【初审通过】**，批语填写“同意举办，内容合规”；
   - 申请单自动流转至二级场地审批队列；
3. 安全退出，切换使用 `manager_01` 登录；
4. 进入 **【场地审批台账】**：
   - 系统自动对该活动时段进行最终时空冲突排查；
   - 点击 **【终审批准】**。此时场地排期正式确认锁定，物资库存被扣减；
5. 此时其他学生若尝试预约该场地的重叠时段，系统会显示冲突活动及其时段，并阻止提交。

#### 3.3 场景三：取消预约与资源动态释放
1. 使用 `student_01` 登录，进入 **【我的申请历史】**；
2. 找到上述已批准的活动，点击 **【取消预约】**；
3. 弹出确认对话框，点击确定；
4. 预约状态变更为 `CANCELLED`，排期中的占用时段随即释放，借用的 2 支麦克风重新计入可借余量。

### 四、 演示数据一键重置

若在运行或测试过程中需要清空临时数据并恢复初始状态，可按如下方式处理：
- **方案 A（界面端操作）**：使用 `admin` 账号登录系统，进入 **【系统管理 -> 数据初始化】**，点击“一键恢复演示数据”；
- **方案 B（命令行终端操作）**：在工程根目录下直接执行：
  ```powershell
  python -m scripts.init_db
  ```
  该命令将自动重置 SQLite 数据库至初始纯净状态。
